
# 🤖 Python Automation Scripts

A collection of powerful Python automation scripts designed to simplify and automate everyday tasks — from auto-filling Google Forms to organizing files and sending emails.

---

## 🚀 Features

- ✅ Google Form Auto Filler
- 📂 File Organizer by Type/Date
- 📧 Bulk Email Sender with Attachments
- 🌐 Website Scraper with CSV Export
- 💬 WhatsApp Message Scheduler
- 📄 PDF Merger and Splitter

---

## ⚙️ Installation

1. **Clone the repo**
```bash
git clone https://github.com/yourusername/python-automation-scripts.git
cd python-automation-scripts
```

2. **Create a virtual environment (optional)**
```bash
python -m venv venv
source venv/bin/activate  # or venv\Scripts\activate on Windows
```

3. **Install required packages**
```bash
pip install -r requirements.txt
```

## 🧪 Scripts Overview

### 1. `auto_form_filler`
Auto-submits Google Forms using Selenium and random data.

### 2. `auto_file_organizer`
Sorts and moves files from a folder into categorized subfolders.

### 3. `auto_email_sender`
Sends emails with attachments using SMTP and a contact list.

### 4. `auto_web_scraper`
Scrapes website data (e.g., headlines) and saves it as CSV.

### 5. `auto_whatsapp_sender`
Sends scheduled WhatsApp messages to contacts via web.

### 6. `auto_pdf_merger`
Merges all PDFs from a folder into one clean file.

---

Please note that the above projects are currently just ideas that we plan to work on. None of the projects have been completed yet.

## 📌 Requirements

- Python 3.8+
- Chrome + ChromeDriver (for Selenium-based scripts)
- `selenium`, `pandas`, `pywhatkit`, `PyPDF2`, `smtplib`, etc.
